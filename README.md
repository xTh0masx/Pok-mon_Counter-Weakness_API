# Pok-mon_Counter-Weakness_API
Input: Pokémon-Name oder Pokémon-Typ (z. B. „Glurak“ oder „Feuer“)  Output: Schwächen des eingegebenen Pokémon bzw. Typs sowie empfohlene Pokémon als Counter. Zusätzlich werden verwendete Typen, Effektivitätsfaktoren und Warnungen ausgegeben, falls z. B. auf gecachte Daten oder einen Fallback zurückgegriffen werden musste.
